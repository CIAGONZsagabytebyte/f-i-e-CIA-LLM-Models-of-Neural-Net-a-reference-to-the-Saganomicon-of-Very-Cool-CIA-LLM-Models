## 🌍 Solarpunk Space Odyssey - Interactive Visualization Game

This PR adds a complete web-based interactive game with a solarpunk aesthetic, combining binary pattern visualization with space exploration themes.

### ✨ Features

- **Three Recursion Levels**: 70, 140, 280 bytes representing Seed → Forest → Civilization
- **Interactive Controls**: Keyboard shortcuts (SPACE, F, C, R, V) and mouse interactions
- **Quantum Garden**: Living nodes that can be activated
- **Biodome Vitals**: Real-time ecosystem monitoring
- **Warp Drive Animation**: Faster-than-light travel visualization
- **Pure Web Tech**: HTML/CSS/JavaScript with no dependencies

### 🎨 Solarpunk Aesthetic

- Vibrant colors: Solar green, space blue, cosmic purple, golden energy
- Animated starfield and nebula effects
- Organic, flowing shapes representing harmony with nature
- Optimistic vision of sustainable space exploration

### 📚 Documentation
