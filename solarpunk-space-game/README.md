# 🌍 Solarpunk Space Odyssey

A beautiful interactive visualization combining binary patterns, space exploration, and solarpunk aesthetics.

## 🚀 Live Demo

[Play the Web Game](./web-game/index.html)

## 🎨 About

Solarpunk Space Odyssey is an optimistic vision of humanity's future - where renewable energy, space exploration, and harmony with nature combine to create thriving civilizations across the stars.

### Core Themes

- 🌱 **Terraforming** - Transforming barren worlds into lush ecosystems
- ☀️ **Solar Energy** - 100% renewable power from the stars
- 🚀 **Space Travel** - Exploring the cosmos sustainably
- 🌳 **Biodiversity** - Preserving and expanding life
- ⚖️ **Harmony** - Balance between technology and nature

## 🎮 Features

### Interactive Elements
- **Navigation Controls** - Toggle warp drive, adjust speed, regenerate biospheres
- **Quantum Garden** - Living nodes you can activate
- **Planet Bits** - Click to terraform worlds (0 ↔ 1)
- **Biodome Vitals** - Real-time ecosystem monitoring
- **Keyboard Shortcuts** - SPACE, F, C, R, V for quick control

### Three Scales of Life

1. **🌱 Seed Pattern (70 Bytes)** - Genesis Protocol
   - The foundation of all life
   - Terraform sequence: 🌍 → 🌿 → 🌳 → 🏞️

2. **🌳 Expansion Pattern (140 Bytes)** - Forest Protocol
   - Growing ecosystems
   - Terraform sequence: 🌱² → 🌲² → 🌍²

3. **🏙️ Civilization Pattern (280 Bytes)** - Harmony Protocol
   - Thriving worlds
   - Terraform sequence: 🌍⁴ → 🌌⁴ → ∞⁴

## 🎯 How to Play

### Keyboard Controls
- `SPACE` - Toggle warp drive
- `F` - Fast mode
- `C` - Cruise mode
- `R` - Regenerate biosphere
- `V` - Switch view

### Mouse Controls
- **Click planet bits** - Transform worlds
- **Click quantum nodes** - Activate living systems
- **Click navigation buttons** - Control your journey

## 🚀 Getting Started

### Local Development

1. Clone the repository
2. Navigate to `solarpunk-space-game/web-game/`
3. Open `index.html` in your browser

Or use a local server:
```bash
cd solarpunk-space-game/web-game
python3 -m http.server 8000
# Visit http://localhost:8000
```

### Deployment

The game is a static website and can be deployed to:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting service
